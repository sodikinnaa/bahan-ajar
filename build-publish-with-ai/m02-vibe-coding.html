Vibe coding: kamu jelaskan, AI menuliskan.

  • Kamu menjelaskan tujuan dalam bahasa biasa.
  • AI menyusun perintah atau kode untuk mencapainya.
  • Hasilnya muncul di terminal yang sama seperti Modul 1.
  • Kamu yang memutuskan menjalankan, mengubah, atau menolaknya.

Kenapa disebut vibe coding

Fokusnya pindah dari mengetik sintaks ke menjelaskan maksud.

Kecepatan bertambah, tapi tanggung jawab memahami tidak hilang.

NOO bilang

Vibe coding bukan berarti asal terima. Semakin cepat AI menulis, semakin penting kamu membaca sebelum menjalankan.

Kesalahan yang sering terjadi

Menyuruh AI mengerjakan semua hal, termasuk yang sebenarnya lebih cepat dan lebih aman dikerjakan sendiri.

Menjalankan perintah dari AI tanpa membaca apa isinya.

Antigravity CLI hidup di server yang sama.

  1. Masuk ke VPS seperti biasa lewat SSH.
  2. Pastikan code-server dari Modul 1 masih berjalan.
  3. Siapkan akun untuk autentikasi Antigravity.
  4. Siapkan folder project yang sudah ada.

NOO bilang

Antigravity CLI dipasang di atas environment Modul 1, bukan menggantikannya. Kalau code-server belum aktif, selesaikan itu dulu sebelum lanjut.

Satu perintah, satu asisten baru di terminal.

Terminal · server (user noodu)
curl -fsSL https://antigravity.dev/install.sh | sh

antigravity --version

Yang terjadi saat instalasi

  • CLI terpasang di folder milik user noodu.
  • Tidak ada file project yang diubah.
  • Perintah antigravity menjadi tersedia di terminal manapun kamu login.

NOO bilang

Output versi yang muncul menandakan instalasi berhasil. Kalau perintah tidak dikenal, buka terminal baru sebelum mengulang.

Hubungkan CLI dengan akunmu.

Jelaskan maksudnya, bukan sintaksnya.

Bedanya dengan mengetik manual

Modul 1: kamu ketik mkdir dan touch sendiri.

Modul 2: kamu jelaskan hasil akhirnya, AI yang menyusun perintahnya.

NOO bilang

Instruksi yang menyebutkan lokasi dan nama secara pasti menghasilkan perintah yang lebih bisa ditebak.

Baca dulu, baru jalankan.

Antigravity CLI · usulan perintah
# AI mengusulkan, belum dijalankan
mkdir -p ~/projects/latihan-ai
touch ~/projects/latihan-ai/index.html

# Jalankan? [y/n]

Wajar diulang

Menajamkan instruksi sampai hasilnya sesuai bukan tanda gagal.

Ini pengganti proses coba-coba yang dulu kamu lakukan manual.

AI menulis draf. Git tetap kamu yang pegang.

Terminal · server
cd ~/projects/latihan-ai
git init
git add .
git commit -m "draf awal dari AI, sudah diperiksa"

Kenapa commit manual

Commit menandakan kamu sudah membaca dan menyetujui perubahan.

Pesan commit yang jujur memudahkanmu melacak bagian mana yang berasal dari AI.

Kita coba bersama, dari instruksi sampai commit.

  1. Pasang dan login ke Antigravity CLI.
  2. Minta AI membuat struktur folder project baru.
  3. Baca usulan perintahnya sebelum menjawab y.
  4. Minta AI menambahkan satu bagian sederhana ke file.
  5. Perbaiki instruksi jika hasilnya belum sesuai.
  6. Commit hasil akhirnya secara manual.

Catat sambil jalan

Simpan instruksi yang berhasil di catatanmu.

Instruksi yang jelas hari ini akan lebih cepat dipakai lagi nanti.

AI mengusulkan ini. Kamu jawab y atau n?

Antigravity CLI · usulan perintah
# instruksi: "bersihkan file lama di folder project"
rm -rf ~/projects/*

# Jalankan? [y/n]

Jawabannya n. Instruksi "bersihkan file lama" tidak sama dengan "hapus semua project". Perintah ini akan menghapus seluruh folder di ~/projects, termasuk pekerjaan dari Modul 1. Instruksi yang vague menghasilkan perintah yang berbahaya. Tulis ulang instruksinya dengan menyebutkan file dan lokasi yang pasti.
