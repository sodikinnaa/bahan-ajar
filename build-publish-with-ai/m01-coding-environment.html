Fondasinya dulu.
Sisanya menyusul.

Komputer sewaan yang tidak pernah kamu matikan.

  • VPS adalah Virtual Private Server.
  • Satu mesin fisik dibagi menjadi beberapa server virtual.
  • Setiap VPS punya IP publik sendiri.
  • Kamu memegang akses penuh lewat terminal.
  • Disewa per bulan dan menyala terus.

Kenapa bukan laptop?

Laptop ikut mati saat ditutup. Server tidak.

Publikasi butuh alamat yang bisa dihubungi kapan saja.

NOO bilang

Spesifikasi kecil sudah cukup untuk modul ini. Satu vCPU dengan 1 GB RAM mampu menjalankan code-server.

Siapkan lima hal sebelum menyentuh terminal.

  1. Akun penyedia VPS yang sudah aktif.
  2. IP publik server.
  3. User dan password awal dari penyedia.
  4. Aplikasi terminal di laptop.
  5. Catatan pribadi untuk menyimpan kredensial.
Terminal · laptop
# pola perintahnya
ssh <user>@<ip-server>

# contoh
ssh root@203.0.113.10

NOO bilang

203.0.113.10 hanya contoh. Pakai IP milikmu sendiri, dan jangan membagikan password server di grup kelas.

Pintu masuknya satu: SSH.

Terminal · laptop
$ ssh root@203.0.113.10

# pertama kali tersambung
Are you sure you want to continue
connecting? yes

# prompt berubah = kamu sudah di server
root@noodu-vps:~#

Tanda kamu sudah masuk

Prompt berubah menjadi nama server, bukan nama laptop.

Setiap perintah yang diketik dijalankan di server.

NOO bilang

Koneksi terputus itu wajar. Ulangi perintah ssh; pekerjaan yang sudah tersimpan tidak ikut hilang.

Jangan ngoding sebagai root.

Terminal · server
apt update && apt upgrade -y

adduser noodu
usermod -aG sudo noodu

su - noodu

Kenapa bukan root?

Root menjalankan apa pun tanpa konfirmasi.

Satu salah ketik dapat merusak seluruh server.

User biasa memaksamu sadar setiap kali menulis sudo.

Satu kali pasang

Ganti laptop, buka browser, semua sudah pada tempatnya.

Tidak ada lagi alasan “di laptop saya jalan, kok”.

Satu perintah untuk memasang editor.

Terminal · server (user noodu)
curl -fsSL https://code-server.dev/install.sh | sh

code-server --version

Yang terjadi saat instalasi

  • Skrip mengenali sistem operasi server.
  • Paket code-server diunduh dan dipasang.
  • Service systemd ikut disiapkan.
  • File konfigurasi awal dibuat otomatis.

NOO bilang

Baca output sampai selesai. Baris “code-server has been installed” menandakan instalasi berhasil.

Hidup sendiri, bahkan setelah server restart.

Terminal · server
sudo systemctl enable --now code-server@$USER

systemctl status code-server@$USER

Baca statusnya

active (running) berarti editor sudah berjalan.

failed berarti ada konfigurasi yang perlu diperiksa.

NOO bilang

enable membuat service ikut menyala saat server dinyalakan ulang. --now menjalankannya sekarang juga.

Tiga baris yang menentukan akses.

~/.config/code-server/config.yaml
bind-addr: 0.0.0.0:8080
auth: password
password: ganti-dengan-punyamu

NOO bilang

Jalankan systemctl restart setelah mengubah file ini. Tanpa restart, konfigurasi lama masih dipakai.

BarisArtinya
bind-addrAlamat dan port yang didengarkan
0.0.0.0Menerima akses dari luar server
8080Nomor port code-server
authCara masuk ke editor
passwordKunci yang kamu pakai sendiri

Alamatnya IP server, bukan localhost.

Browser · laptop
http://203.0.113.10:8080

# bukan ini, karena localhost
# menunjuk ke laptopmu sendiri
http://localhost:8080

Belum bisa dibuka?

Port 8080 mungkin masih tertutup firewall server.

Itu pembahasan Modul 4: Understanding Port.

Untuk sekarang, pastikan service sudah active.

Pasang sesuai kebutuhan

  • Git untuk menyimpan riwayat kode.
  • Runtime bahasa yang dipakai project.
  • Extension dari panel kiri editor.

NOO bilang

Pasang yang dibutuhkan saja. Menambah paket nanti jauh lebih mudah daripada membersihkan server yang sudah penuh.

Rapi sejak awal, gampang dicari nanti.

Struktur di ~/projects
~/projects
├── latihan/
├── final-project/
└── CATATAN.md

Aturan sederhana

  • Satu project satu folder.
  • Nama folder huruf kecil tanpa spasi.
  • Semua project berada di bawah ~/projects.
  • IP, user, dan port dicatat di CATATAN.md.

Kita pasang bersama, langkah demi langkah.

  1. Masuk ke server lewat SSH.
  2. Perbarui paket sistem.
  3. Buat user kerja dan beri akses sudo.
  4. Pasang code-server.
  5. Nyalakan service dan periksa statusnya.
  6. Ubah password pada config.yaml.
  7. Buka editor lewat browser.

Catat sambil jalan

Tulis IP, nama user, dan port di catatanmu.

Ketiganya dipakai lagi mulai modul berikutnya.

menyiapkan markasnya.

Service active, browser tetap kosong. Kenapa?

Temukan masalahnya · config.yaml
bind-addr: 127.0.0.1:8080
auth: password
password: rahasia123

127.0.0.1 hanya menerima koneksi dari dalam server itu sendiri. Browser di laptopmu datang dari luar, sehingga permintaannya ditolak sebelum sampai ke editor. Ganti menjadi 0.0.0.0, restart service, lalu coba buka kembali.
