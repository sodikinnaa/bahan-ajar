# Noodu Slide Generator

A PHP-based system for generating educational slide modules using AI. This application integrates with OpenAI-compatible APIs to create professional presentations from text prompts and reference materials.

## Features

- **AI-Powered Generation**: Use OpenAI or compatible APIs to generate slide content
- **Dynamic Model Selection**: Fetch and select from available models
- **File Upload Support**: Upload PDF or PNG reference materials
- **PDF Export**: Generate publication-ready PDFs
- **Project Management**: Store and manage generated presentations
- **Revision Workflow**: Track and manage revisions to slides
- **Secure Authentication**: Protected access with admin login

## Requirements

- PHP 7.4+
- cURL extension
- `poppler-utils` (for PDF text extraction): `apt-get install poppler-utils`
- `chromium-browser` or Chromium (for PDF generation from HTML)
- Write permissions for `app/database`, `app/uploads`, `app/output`

## Usage

### Running the Application

1. **Start a PHP server**:
   ```bash
   cd /path/to/bahan-ajar/app
   php -S localhost:8000
   ```

2. **Access the application**:
   - Open `http://localhost:8000` in your browser
   - Login with credentials: `admin` / `@noodu2026`

### Generating Slides

1. **Configure OpenAI API**:
   - Enter Base URL (e.g., `https://api.openai.com/v1`)
   - Paste your API key
   - Click "Fetch Available Models"

2. **Create Project**:
   - Enter project name
   - Optionally upload reference PDF or image
   - Write your prompt describing the slides
   - Click "Generate Slides"

3. **Download PDF**:
   - View generated project
   - Click "Download PDF"
   - Use default page size: **13.333 × 7.5 inches** when printing

### Managing Revisions

1. Navigate to project details
2. Enter revision prompt
3. Submit to track changes

## API Endpoints

### Authentication
- `POST /api/login.php?action=login` - Login with credentials
- `GET /api/login.php?action=check` - Check authentication status
- `POST /api/login.php?action=logout` - Logout

### Models
- `POST /api/models.php` - Fetch available models from OpenAI API
  - Required: `base_url`, `api_key`

### Generation
- `POST /api/generate.php` - Generate slide content
  - Required: `base_url`, `api_key`, `model`, `prompt`, `project_name`
  - Optional: Upload file as `reference_file`

### Projects
- `GET /api/projects.php?action=list` - List all projects
- `GET /api/projects.php?action=get&id=<id>` - Get project details
- `POST /api/projects.php?action=revise` - Submit revision
- `POST /api/projects.php?action=delete` - Delete project

### Download
- `GET /api/download.php?id=<id>` - Download project PDF

## Troubleshooting

### PDF Generation Fails
- Ensure Chromium is installed: `which chromium-browser`
- Check file permissions in `output/` directory
- Verify HTML generation by checking temporary files

### PDF Text Extraction Fails
- Install poppler: `sudo apt-get install poppler-utils`
- Test with: `pdftotext /path/to/file.pdf`

### API Errors
- Verify Base URL format (include `/v1` for OpenAI)
- Check API key validity
- Ensure model name is correct

### File Upload Issues
- Check directory permissions on `uploads/`
- Verify file size is under 10MB
- Ensure file type is PDF, PNG, or JPEG

## Security Notes

- Change default admin password in production
- Use HTTPS for API communication
- Restrict file upload sizes if needed
- Implement rate limiting for API endpoints
- Secure database backups
